# SmartERP Keyboard Navigation System

---

# Introduction

SmartERP is designed as a keyboard-first ERP system inspired by TallyPrime.

The objective is to allow accountants and business users to perform every operation without using a mouse.

Keyboard navigation improves speed, accuracy, and productivity.

---

# Navigation Principles

Every screen should support:

- Arrow Keys
- Enter
- Tab
- Shift + Tab
- Escape

The user should never need a mouse for daily operations.

# Design Guidelines

Every form should:

- Open without mouse interaction.
- Focus automatically on the first input.
- Support Tab navigation.
- Support Shift + Tab.
- Allow Enter to save data.
- Allow Escape to cancel.
- Support arrow key navigation in tables.
- Provide keyboard shortcuts for all major actions.

---

# Objective

The entire SmartERP application should be fully usable using only the keyboard, providing a workflow similar to TallyPrime while maintaining a modern web-based user interface.
